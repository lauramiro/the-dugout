# Demo replay files (seed 73)

Every file here is generated by `uv run python web/scripts/build_demo_fixtures.py` from the recorded demo match in `data/` (`demo-rfc-cas-0073.jsonl` and its tracking file). Nothing is hand-shaped; rerun the script whenever the state engine, the decision engine or the agents change.

- `match.jsonl`: events (contract 1), a copy of `data/demo-rfc-cas-0073.jsonl`.
- `tracking/`: tracking frames (contract 2) thinned from 2 Hz to 1 Hz and split into 10-minute chunks (`index.json`).
- `roster.json`: names and roles from `scenarios/riverside-castleton.yaml`.
- `snapshots.jsonl`: snapshots (contract 3) every 10 s from `dugout.stream.state_engine`.
- `cards.json`: one card per decision point from `dugout.stream.triggers`. Each holds the payload (contract 4) from `dugout.engine.payload.decide` on the point's snapshot, with `manager_action` filled from the deciding team's `sub` events; the narration from `dugout.agents.pipeline` with the stub client (template text, through the grounding check) for each locale and mode; when the card closed; and a `review` block for the full-time screen (the manager's call priced by the engine on the card's own draws, the gap to the model's call, and a template recap line).
- `winprob.jsonl`: home win probability once a minute, the engine's no-change run on that minute's snapshot. Not one of the four contracts.
